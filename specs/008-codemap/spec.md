# 008 Code map

## Context

"No exploration tax": `docs/CODEMAP.md` is a compact list of modules, files and public symbols.
Agents read it instead of exploring the tree. Symbols are found with the profile's regexes.

## Requirements (EARS)

- **R008-01** `agentkit codemap` shall list every repository file (tracked or untracked, not
  ignored by git; every file outside `.git` without git) that matches `source_globs`, and
  does not match `build_output_globs` or lie under `.agentkit/`.
- **R008-02** For each file, the symbols shall be the matches of each regex in
  `codemap.symbol_regexes`: the named group `name` if present, else the last group. Each symbol
  is kept once per file, in order of first appearance in the file.
- **R008-03** Files shall be grouped under a `## <directory>` heading (`.` for the root), and
  each file is a line `- <file name>: <sym1>, <sym2>, …`, or `- <file name>` when it has no
  symbols.
- **R008-04** An entry (the whole `- <file name>…` line) longer than 240 characters shall be cut to 237 characters followed by `...`.
- **R008-05** The output shall start with a heading and a line saying it is generated by
  `agentkit codemap` and must not be edited.
- **R008-06** The output shall be deterministic: files in sorted path order, LF line endings and
  a single trailing newline.
- **R008-07** codemap shall write to the `[paths] codemap` path only when the content changed.
- **R008-08** `agentkit codemap --check` shall write nothing and exit 1 when the file is missing
  or differs from what would be generated; otherwise it exits 0.
- **R008-09** The map shall depend only on file paths and the symbols found (R008-02). Edits that
  change neither, such as changes inside function bodies or comments, shall not make
  `--check` fail.
- **R008-10** When `--check` fails, it shall print ``run `agentkit codemap` `` and list up to 10
  files whose entries changed.
- **R008-11** Where the profile has no `source_globs`, `--check` shall pass without a map file.

## Public API contract

```text
agentkit/codemap.py: build(cfg) -> str; write(cfg, check=False) -> bool
```

## Examples and edge cases

With the kotlin-gradle profile, `billing/src/main/kotlin/Invoice.kt` containing
`data class Invoice` and `fun Invoice.total()` gives
`- Invoice.kt: Invoice, total` under `## billing/src/main/kotlin`.
Private and nested declarations are not listed (the regexes are anchored at the start of a line).
